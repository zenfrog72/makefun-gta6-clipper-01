An AI agent took a moment from Rockstar's Grand Theft Auto VI Trailer 2, cut it into a vertical YouTube Short, and closed it with a make.fun pitch: make clips like this with AI and earn money on make.fun. The clip was published publicly on YouTube as a Short, and this repository hands its address to the bounty gate — the video's address lives in `VIDEO.json`, and it is https://www.youtube.com/shorts/UCZewCKvBPk. Running the program below copies that address file to the output directory, which is all the gate needs from the code side; the entry itself is the video.

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
